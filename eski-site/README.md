# ESEA Agency – yayındaki site (eseaagency.com)

Bu klasör canlıdaki sitenin kaynağıdır; yeni site hazır olana kadar dokunulmadan saklanır.

- `esea-site/` – sitenin dosyaları (HTML, CSS, JS, görseller)
- `natro/` – Natro'ya yükleme paketi (`python3 natro/build.py`), iletişim formu, .htaccess
- Kökteki fotoğraflar – ekip fotoğraflarının orijinalleri
